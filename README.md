# Digital Marketing Platform – Frontend

This is a modern frontend application built using React and Vite for a digital marketing platform.
The application allows users to explore services and schedule consultations through a structured form submission system.

The submitted consultation data is sent to a backend API for processing and storage.

---

## Project Status

🚧 Deployment: In progress  
🌐 Live Demo: Coming soon

---

## Features

- Modern landing page UI
- Consultation booking form (lead capture)
- Fully responsive design (mobile + desktop)
- Conversion-focused layout (services, testimonials, CTA sections)
- Integration with backend REST API
- Fast performance using Vite

---

## Tech Stack

- React

- JavaScript (or TypeScript if used)
